# API Pressure Lab

API Pressure Lab 是一个运行在 Windows 本机的 API 压测控制台，支持 NewAPI、OpenAI 兼容接口、Claude Messages 和 Gemini generateContent。

项目使用 React、Vite 和 Express 构建。界面分为页面导航、当前工作区和常驻运行状态三部分，可配置多个 API，观察实时指标，并保留本地历史记录。

## 运行环境

- Windows 10 或 Windows 11
- Node.js 20.18.1 或更高版本
- npm 10 或兼容版本
- 默认服务地址：`http://127.0.0.1:4217`

## 启动

双击根目录的 `Start.bat`。

它会自动完成：检查 Node.js、按需安装依赖、构建 WebUI、启动本机服务，并打开浏览器到 `http://127.0.0.1:4217`。

结束方式：在启动窗口按 `Ctrl+C` 直接结束，无需二次确认。

也可以在终端中停止服务：

```powershell
.\Start.bat stop
```

手动方式：

```powershell
npm ci
npm run build
npm start
```

然后打开 `http://127.0.0.1:4217`。

开发模式分两个终端运行：

```powershell
npm run server
npm run dev
```

开发模式前端地址通常是 `http://127.0.0.1:5173`。

## 使用边界

只对自己拥有或已经获得明确授权的 API 服务进行压力测试。建议从较低的 RPM、并发数和请求总量开始，确认服务限额、计费方式与上游使用条款后再提高负载。

项目默认只监听 `127.0.0.1`。如果修改监听地址，请同时评估访问控制、网络暴露和本地 API Key 的安全风险。

## 页面结构

左侧导航为真实页面切换，一个按钮对应一个界面：

- 总览：当前模式摘要、核心运行状态、最近运行结果、快捷入口
- API 配置：多 API 独立配置、协议、Base URL、模型、脱敏 Key、代理、路径预览
- 负载与代理：RPM、总请求数、最大并发、随机抖动、重试、失败自动停止、全局代理、请求体最大输出 token
- Prompt 库：权重 / 滚动双策略、期望输出 token 区间、Prompt 列表、按协议请求预览、正文二次展开
- 运行监控：趋势图、P50 / P95 / P99、错误分布、最近错误、按 API 统计、当前 Prompt 轨迹
- 历史与错误：历史运行记录、关键错误聚合、历史模式摘要、常见失败原因

右侧状态栏在所有页面常驻，只显示 6 项：运行状态、运行时间、实际 RPM、成功 / 失败、当前 Prompt 分区、停止 / 暂停 / 继续。

点击右侧「开始」会开启一轮新的压测计数：右侧状态栏、总览页本轮计数和运行监控会从 0 重新开始。上一轮请求日志不会丢失，会保存在 `data/runs/*.jsonl`，并继续出现在「历史与错误」页面的历史记录、累计统计和错误聚合里。

暂停会冻结本轮运行时间，并丢弃暂停前尚未发出的排程；继续后按当前配置重新规划后续请求，避免暂停期间积压请求在继续时集中发出。

## Prompt 双策略

两条独立路线，互不兜底，默认权重模式：

- 权重模式：按 `2-5w / 5-10w / 10-15w / 15-20w` 四个分区的百分比抽样（默认 10 / 35 / 35 / 20），合计 100%，单项可为 0%。适合短期大规模冒烟测试。
- 滚动模式：模拟真实对话逐轮增长。首条从 `2-5w` 随机开始，每轮在上轮 token 基础上加随机增量（默认 3000-5000），在 100 条有序库中取最接近的一条；超过 20w 上限后压缩重启回到 `2-5w`。

## 输出 token 双层规则

- 期望输出 token：写入 Prompt 的目标值，用户设最小值 / 最大值 / 步长（默认 1500 / 3000 / 500），候选为整齐整数阶梯，按正态分布抽样。
- 请求体最大输出 token：全局统一配置（默认 20000，范围 1024-65535），下发到所有请求的 max_tokens。

## 默认能力

- 1-10 个 API 独立配置
- OpenAI Chat、Claude Messages、Gemini generateContent 三种协议
- RPM 随机节奏调度
- 流式和非流式请求
- 默认 HTTP 代理 `http://127.0.0.1:7897`
- 本地安全合成中文长 Prompt 库，固定 100 条
- API Key 永久脱敏显示，保留头尾字符
- 本地日志 `data/runs/*.jsonl`
- 历史日志清除入口：在「历史与错误」页停止运行后可清除历史日志和当前错误统计
- 窄屏自适应：桌面三栏布局会在平板和手机宽度下折叠为更适合触控的结构

## 测试

安装锁文件指定的依赖并运行完整检查：

```powershell
npm ci
npm test
npm run build
```

测试只使用本地 mock 服务，不会向真实第三方 API 发送请求。

## 项目结构

```text
server/     Express 服务、压力调度、协议适配与本地日志
src/        React WebUI
scripts/    Windows 进程启动与停止辅助脚本
tests/      Vitest 单元测试和本地协议测试
Start.bat   Windows 启动入口
```

## 隐私与本地数据

- `data/config.json` 可能以明文保存 API Key，浏览器本地存储也会保存当前配置。
- `data/`、`node_modules/`、`dist/`、运行日志和 PID 文件均被 Git 忽略。
- 请求预览和配置接口会对 API Key 脱敏，但仍应避免分享本地配置文件、浏览器数据目录和运行日志。
- 仓库不包含示例密钥，提交前应再次运行敏感信息扫描。
